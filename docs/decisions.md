## 2026-10-04：RK4 与 GR/EGB 背景

按用户指定的 PNJLs `TOV` 分支 `tov_geo.jl`（commit
`dc6706f38a75eee0a6742890e027379891ed1051`）实现平铺的 `src/numerics.py`
与 `src/structure.py`。作用量与分支先固定于 [equations_egb.md](equations_egb.md)。
使用有理化后的共同 RHS，alpha=0 即 GR，小 alpha 无相减损失。
入口采用中心压力，单位显式为 km、km⁻²、km²。

常规区域经典 RK4；中心用 q=m/r³、级数初值及 h≤r/2，表面按压力变化尺度
限步并在越界时拒绝缩步。
直接积分 m 的中心中间级导致二阶收敛，因此内部改用 q；对外结果仍是 m。
JIT + while_loop 保留提前终止，序列用 lax.map 保留标量 EOS 范围保护。
第一版只返回端点与状态；无完整表面时不报告整星 M/R。
表格 PCHIP 预处理使用 SciPy，实际计算为纯 JAX；不添加内部密度跳变匹配。

## 2026-10-04：输出目录覆盖原约定

按用户新要求，示例输出改为固定路径 `data/example——NJL0/eos.csv` 和 `eos.svg`，
不再为此示例生成时间戳目录或 JSON/YAML 等旁置文件。

此要求优先于项目初始设计中的每次运行单独建目录和保存完整记录的规则。

临界 Gv 使用所追踪 EOS 的压缩率极小值归零定位，并以局域电中性相的
等 μB、等 P 和密度跃变缩小核查。一维耦合搜索不改变 gap 的单初值延拓策略。
常数 B_eff 不影响内部临界耦合；未由此推断其他相态或真空边界不存在相变。

## 2026-10-04：独立零温 NJL 示例

当前工作按用户要求放在 `example/`，不预先建立设计文档中的整个 `src` 架构。
模型和验收脚本分开，文件名用可导入的 `NJL_T0.py`。

采用用户指定的 PNJLs 仓库参数和逐味矢量约定，参考 commit 为
`08a32a6660ee1b2e0d9a4bf04236071bbc9734cd`。
来源链接、公式和单位列在 [example/README.md](../example/README.md)。

用户后续明确要求高性能单初值延拓，最终网格调整为从 `1e-8` 向上到 `6`，
默认间隔 0.01；不采用初始讨论中的向下 3→0.01 扫描，也不做多初值选根。
以 JAX `lax.scan` + Optimistix Newton 实现，后处理使用 `vmap`。
此示例只追踪一个均匀物质分支，全局根比较、Maxwell/Gibbs 留待独立阶段。

`B_eff` 遵循项目原设计：MeV/fm³，压力减、能量密度加。
默认 Rv=0/0.25/0.5/1、B_eff=0 已经用户确认；电子和 μ 子保留真实质量与阈值。

TOV 输出明确区分完整零压端点与仅核心分支，不通过删除原始数据或平滑
不稳定区伪造完整 EOS。原始扫描表始终保留全部点。

项目先前的 `.python-version` / 虚拟环境为 3.9，与 `pyproject.toml` 的 3.14
要求不一致。已对齐到 Python 3.14，重新生成当前项目的 `uv.lock` 并安装验证。
